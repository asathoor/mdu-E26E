# HTML Designsystem

Formålet med et HTML Designsystem er at demonstrere, hvordan dit design faktisk ser ud i en browser. Designsystemet demonstreres i filen:

* designsystem.html

## Designsystem.html

Består af markup, der viser hvordan de forskellige elementer er konstrueret. I denne fil kan du vise, hvordan sitets elementer er konstrueret, fx cards med call to actions etc.

## ./css/designsystem.css

Særlig css til designsystem.html - med css, der ikke er nødvendig i den egentlige produktion.

## ./css/css.css

Er den centrale css-fil i dit design med alle sitets styles.
